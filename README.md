# 2027 휘경여고 과목 선택 시스템

학생들이 진로에 맞는 선택과목을 고르고, 수강신청 조건을 직접 확인할 수 있는 웹페이지입니다.

**원칙: 구글 시트 하나로 3개 학년을 관리하고, 해마다 바뀌는 내용은 시트에서만 고칩니다. 코드는 고치지 않습니다.**

```
[구글 시트 1개] → [Apps Script: 선택한 입학년도에 필요한 탭만 전달] → [웹페이지 index.html]
```

## 파일 구성

| 파일 | 내용 |
|---|---|
| `config.js` | **설정** — 제목, 제작자 표시, 구글 시트(Apps Script) 주소. 이 파일만 고치면 바로 반영 |
| `src/index.html` | 화면 **원본** 코드 (수정은 여기서) |
| `index.html` | 학생에게 보이는 페이지 — `src/index.html`을 압축해 **자동으로 만든 파일** (직접 고치지 않음) |
| `build/build.js`, `package.json` | 압축 도구 (`npm install` → `npm run build`) |
| `.github/workflows/build.yml` | `src/` 가 바뀌면 GitHub가 `index.html`을 자동으로 다시 만듦 |
| `apps-script/Code.gs` | 구글 시트의 Apps Script에 붙여 넣을 코드 |
| `sheet/통합시트_예시.xlsx` | 시트 구성 예시 (2026 실제 자료, 2027 복사본, 2025 빈 틀) |

## 시트 구성

| 색 | 탭 | 내용 |
|---|---|---|
| 🟧 | **기본정보** | 입학년도별 열(2025·2026·2027): 학생공개, 운영과정, 학교명, 수능년도, 자료출처, **공지** |
| 🟩 공통 | 계열데이터 · 학과데이터 · 대학별 이수권장과목 | 진로별 추천 과목 |
| 🟩 공통 | **과목소개** | 과목 한줄소개·키워드·학습활동·추천학생·영상 (과목명으로 연결) |
| 🟩 공통 | 공유캠퍼스 · 거점형 선택 교육과정 | 운영 학교와 과목 |
| 🟩 공통 | 직업데이터 | 직업 · 관련 과목 · **하는 일** · **과목별 추천 이유**(`과목명: 이유 → 배우는 내용` 한 줄씩) · **관련 학과**(쉼표로, 예: `국어교육과, 국어국문학과`) · **학과별 추천 이유**(`학과명: 이유` 한 줄씩. 비어 있으면 학과데이터의 학과 소개 첫 문장) · **계열**(인문·사회·경영·경제·교육·자연과학·공학·IT·정보·의약·보건·예술·체육·생활·서비스 중 하나 → [직업으로 찾기]의 계열 타일) → [진로 찾기 → 직업으로 찾기]. 관련 학과 칸이 비어 있으면 학과데이터의 '졸업 후 진로'에 직업 이름이 그대로 나오는 학과를 찾음 |
| 🟨 공통 | **AI직업데이터** | 위 51개 외 직업 약 290개 (AI가 만든 자료). 직업데이터와 같은 형식 + 계열·관련 학과·학과별 추천 이유 열. 화면에 **🤖 AI추천(주의!! 상담 및 고민 필요)** 이 꼭 함께 표시됨. 선택과목 + 이 직업과 이어지는 2·3학년 지정 과목(따로 표시). 검토를 마친 직업은 [직업데이터]로 옮기면 AI 표시가 사라짐 |
| 🟪 자동 | **대학학과정보** | 학과별 개설 대학(4년제·전문대, 소재지, 대학 학과명, 홈페이지). 시트 메뉴 **[🎓 대학 정보] → [커리어넷에서 불러오기]** 로 1년에 한 번 자동으로 채움. 양이 많아 학생이 학과를 누를 때만 그 학과 부분을 받아 감 → [직업으로 찾기] → [관련 학과·대학도 살펴보기] |
| 🟪 자동 | **커리어넷직업** | 커리어넷 직업백과(하는 일, 적성·흥미, 관련 학과·자격, 임금, 전망, 되는 길). 시트 메뉴 **[🎓 대학 정보] → [📘 커리어넷 직업백과 불러오기]** 로 1년에 한 번 채움. 직업을 고를 때 그 직업 부분만 받아 감. AI추천 직업도 직업백과에 있으면 설명·관련 학과는 공식 자료로 보여 줌 |
| 🟩 공통 | 용어풀이 | 화면의 ⓘ 버튼과 [도움말]의 용어 설명 (없으면 기본 설명 사용) |
| 🟦 학년별 | **2027_선택군** | 선택군(A~K): 학기, 몇 과목 선택, 학점, 공유캠퍼스 여부 |
| 🟦 학년별 | **2027_규칙** | 수강신청 조건 (예전 [조건] 탭을 대신함) |
| 🟦 학년별 | **2027_과목데이터** | 학년마다 다른 것만: 과목명, 편성, 학점, 교과군, 선택유형, 평가, 수능출제 |
| 🟦 학년별 | 2027_편제표 | 학점 배당표 (보관용, 현재 화면에서는 사용하지 않음) |
| ⬜ | `_`로 시작하는 탭 | **웹페이지로 보내지 않음** (사용안내, 규칙작성법, 메모, 학생 명단 등) |

- 학년별 탭은 반드시 `4자리 연도_탭이름` 형식으로 짓습니다. 같은 이름이면 학년별 탭이 공통 탭보다 먼저 쓰입니다(예: `2027_공유캠퍼스`).
- **학생공개**: O이면 화면 상단 **입학년도 선택 상자**에 보이고, X이면 숨겨집니다. 숨긴 학년도 `?year=2027`을 붙이면 미리보기할 수 있습니다.
- 학생이 상단 선택 상자에서 입학년도를 고르면 같은 페이지가 그 학년 내용으로 새로고침되고, 기기에 기억됩니다. 처음 접속하면 공개된 가장 최근 입학년도로 열립니다.
- **운영과정**: `일반, 과학중점` 또는 `일반`. `일반`만 적으면 과학중점 선택이 사라지고 일반 과정으로 고정됩니다(2027 입학생부터).
- 규칙 작성법은 예시 파일의 `_규칙작성법` 탭에 있습니다.

## 화면 구성

| 메뉴 | 하위 화면 |
|---|---|
| ① 진로 찾기 | 직업으로 찾기 · 학과 가이드 · 대학별 이수권장 |
| ② 과목 고르기 | 나의 편제표 · 선택과목 가이드 · 과목 비교 (왼쪽: 과정 설정과 학기별 과목 카드) |
| ③ 내 결과 | 조건 점검·공유(공유 링크) · 나의 보고서 |
| ❓ 도움말 | 처음 오셨나요?, 용어 풀이, 자주 묻는 질문 |

- **글자 크기:** 제목 옆 **[가 가 가]** 버튼(보통·크게·아주 크게). 기기에 기억되고, 넓은 모니터(1440px 이상)는 처음부터 '크게'
- **좌우 비율:** PC에서 가운데 막대를 끌어 조절 (두 번 누르면 반반)
- **직업으로 찾기:** [직업데이터]와 [AI직업데이터]를 한 목록으로. 검색(직업 이름·관련 학과·관련 과목·하는 일) + 계열 타일 + 내 희망 진로와 이어지는 직업 + 최근 본 직업
- **맨 위:** 알림 띠(기본정보의 공지), 통합 검색(과목·학과·직업·대학), 진행 표시줄(과정 → 진로 → 과목 → 조건 → 공유)
- **휴대폰:** 화면 아래 고정 메뉴 막대
- **공유 링크:** 이름·학번은 담지 않습니다. 받은 사람은 보기 전용으로 보고, [내 기기에 저장하고 수정하기]로 가져올 수 있습니다.
- **공지 쓰는 법:** 기본정보의 공지 칸에 한 줄씩 적습니다. `2027-03-05 수강신청 마감`처럼 날짜를 앞에 쓰면 D-day가 붙고, 날짜가 지나면 숨겨집니다.

## 해마다 하는 일 (새 입학년도)

1. 작년 학년별 탭(선택군·규칙·과목데이터, 필요하면 편제표)을 복사하고, 이름 앞 연도를 바꿉니다. 예: `2028_과목데이터`
2. [기본정보]에 새 연도 열을 추가합니다. 학생공개는 처음에 **X**로 둡니다.
3. 바뀐 내용을 고칩니다: 선택군 → 규칙 → 과목데이터(편성). 새 과목이 생겼으면 [과목소개]에 한 줄 추가합니다.
4. 페이지 주소 뒤에 `?year=2028&check=1`을 붙여 **시트 점검 결과**를 확인합니다. ⚠️ 항목을 모두 고칩니다.
5. 학생공개를 **O**로 바꿉니다.
6. 졸업한 학년의 학년별 탭과 [기본정보]의 해당 열을 지웁니다.

**코드와 Apps Script는 고칠 필요가 없습니다.** 시트를 고친 내용은 학생이 새로고침하거나 🔄 데이터 최신화를 누르면 반영됩니다.

## Apps Script 처음 설정 · 수정할 때

- 처음: 시트에서 **확장 프로그램 → Apps Script**를 엽니다. `Code.gs` 내용을 붙여 넣고 **배포 → 새 배포**(유형: 웹 앱, 액세스: 모든 사용자)를 누릅니다. 나온 주소를 `config.js`의 `SHEET_URL`에 넣습니다.
- Apps Script 코드를 수정한 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 순서로 합니다. 이렇게 하면 주소가 바뀌지 않습니다.

## 대학 정보(커리어넷) 설정

1. 커리어넷(career.go.kr) → 오픈API에서 인증키를 발급받습니다. (무료)
2. Apps Script에 새 `Code.gs`를 붙여 넣고 **배포 관리 → 새 버전**으로 배포합니다. (주소 그대로)
3. 시트를 새로고침하면 위쪽에 **[🎓 대학 정보]** 메뉴가 생깁니다. **[🔑 커리어넷 인증키 저장]** → **[⬇️ 커리어넷에서 불러오기]** 순서로 누릅니다. 처음에는 권한 승인 창이 뜹니다.
4. 학과가 많아 몇 분~십여 분 걸립니다. 6분 제한에 걸리면 **1분 뒤 자동으로 이어서** 진행하고, [대학학과정보] 탭 J1 칸에 진행 상황과 불러온 날이 표시됩니다.
5. 결과가 비어 있으면 `_커리어넷_응답예시` 탭(웹페이지로 보내지 않음)에 받은 응답이 저장되어 있으니 원인을 확인할 수 있습니다.

- **직업백과:** 같은 메뉴의 **[📘 커리어넷 직업백과 불러오기]** 를 누르면 [커리어넷직업] 탭이 채워집니다. (대학 정보와 따로, 1년에 한 번)
- **진로상담 사례:** 따로 불러올 필요가 없습니다. 학생이 [💬 진로상담 사례 보기]를 누를 때 그 직업 낱말로 커리어넷에서 찾아 제목·앞부분만 보여 주고, 전문은 커리어넷으로 연결합니다. (6시간 동안 저장해 재사용)
- 입시 정보(전형·모집 인원·입시 결과)는 해마다 바뀌어 시트에 담지 않고, 화면에서 **대입정보포털 '어디가'**와 각 대학 **모집요강**으로 연결합니다.

## 압축(빌드)에 대하여

- 학생에게 보이는 `index.html`은 화면 코드를 미리 변환·압축한 파일입니다. 소스를 읽기 어렵게 하고, 첫 화면을 빠르게 합니다(브라우저에서 2.8MB 변환 도구를 내려받지 않음).
- **설정만 바꿀 때**: `config.js`만 고치면 됩니다. 다시 만들 필요가 없습니다.
- **화면 코드를 바꿀 때**: `src/index.html`을 고치면 GitHub Actions가 `index.html`을 자동으로 다시 만듭니다. 직접 하려면 `npm install` 후 `npm run build`.
- 원본 확인용 화면: `…/src/index.html` 주소로 열면 압축 전 원본으로 동작합니다(느림).
