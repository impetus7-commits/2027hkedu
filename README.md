# 휘경여고 과목 선택 시스템

학생들이 진로에 맞는 선택과목을 고르고, 수강신청 조건을 직접 확인할 수 있는 웹페이지입니다.

**원칙: 해마다 바뀌는 내용은 모두 구글 시트에 있고, 코드는 고치지 않습니다.**

```
[구글 시트] → [Apps Script: 모든 탭을 데이터로 전달] → [웹페이지 index.html]
```

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 웹페이지 |
| `apps-script/Code.gs` | 구글 시트의 Apps Script에 붙여 넣을 코드 |
| `sheet/추가할_탭_양식.xlsx` | 시트에 추가할 탭 3개(기본정보·선택군·규칙)와 작성법 |

## 시트 탭 구성

| 탭 | 하는 일 | 매년 확인 |
|---|---|---|
| **기본정보** | 학교명, 입학년도, 수능년도, 자료출처 | ✅ |
| **선택군** | 군ID(2A…), 화면 표시이름(A…), 학기, 몇 과목 선택, 학점, 공유캠퍼스 여부 | ✅ |
| **규칙** | 수강신청 조건 (국·수·영 21학점, 과학중점 79학점, 지정과목 등) | ✅ |
| 과목데이터 | 과목명, 편성(예: `2학년 2A군(2학년 1학기) 선택`), 학점, 교과군, 소개 | ✅ |
| 공유캠퍼스 | 운영 학교와 과목 (과목 카드에 학교명 표시) | ✅ |
| 계열데이터 · 학과데이터 · 대학별 이수권장과목 | 진로별 추천 과목 | 필요할 때 |
| `_`로 시작하는 탭 | **웹페이지로 보내지 않음** (메모, 학생 명단 등) | |

규칙 작성법은 `sheet/추가할_탭_양식.xlsx`의 `_규칙작성법` 탭에 있습니다.

## 해마다 하는 일 (새 입학년도)

1. 작년 구글 시트를 **사본 만들기**. 이름 예: `2027 입학생 과목선택`
2. 사본에서 바뀐 칸만 고치기: 기본정보 → 선택군 → 규칙 → 과목데이터 → 공유캠퍼스
3. 사본의 **확장 프로그램 → Apps Script → 배포 → 새 배포**(유형: 웹 앱, 액세스: 모든 사용자). 새 시트이므로 주소가 새로 생깁니다.
4. `index.html` 맨 위 `SHEET_URLS`에 한 줄 추가하고 `DEFAULT_YEAR`를 바꾸기
   ```js
   const SHEET_URLS = {
     '2028': 'https://script.google.com/macros/s/……/exec',   // ← 추가
     '2027': '……',
     '2026': '……',
   };
   const DEFAULT_YEAR = '2028';
   ```
5. 페이지 주소 뒤에 `?check=1`을 붙여 **시트 점검 결과**를 확인하고, ⚠️ 항목을 모두 고친 뒤 학생들에게 공개하기

재학 중인 다른 학년은 `?year=2026`처럼 입학년도를 붙인 주소로 계속 안내합니다. 학생의 선택 기록도 입학년도별로 따로 저장됩니다.

## 같은 해 안에서 내용을 고칠 때

시트만 고치면 됩니다. 학생이 페이지에서 **🔄 데이터 최신화**를 누르거나 새로고침하면 바로 반영됩니다. Apps Script를 다시 배포할 필요는 없습니다.

Apps Script **코드**를 고친 경우에만 다시 배포해야 합니다. 이때는 반드시 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 순서로 하세요. 이렇게 해야 주소가 바뀌지 않습니다.
